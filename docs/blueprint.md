# **App Name**: CleanSweep App

## Core Features:

- Training Modules: Record and display training modules for Environmental Services (EVS) staff on hospital cleanliness procedures, incorporating Joint Commission, EHS, OSHA regulations.
- Cleaning Checklists: Create and display checklists for housekeeping staff to ensure consistent cleaning and inspection standards.
- Inspection Reporting: Generate reports based on inspection data to identify areas needing improvement. This serves as a tool.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to convey cleanliness and hygiene.
- Secondary color: White (#FFFFFF) for a clean and sterile feel.
- Accent: Royal Blue (#4169E1) to indicate compliance and positive results.
- Clean, well-organized layout with clear sections for training, checklists, and reports.
- Use simple, recognizable icons to represent different cleaning tasks and areas.
- Subtle transitions and animations to provide feedback on task completion and report generation.
